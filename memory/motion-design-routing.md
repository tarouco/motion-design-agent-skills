## Motion design: use the motion-design-agent-skills plugin

For any request about motion design, UI or web animation, transitions, micro-interactions, scroll effects, motion QA or reduced-motion support, Remotion or programmatic video, GIF/MP4/WebM export, or AI-generated images and video (including requests in Portuguese such as "animação", "transição", "efeito de scroll", "revisar animações", "vídeo em React", "exportar GIF", "gerar vídeo com IA"), load the `motion-design-orchestrator` skill first. In Claude Code and Cowork it is `/motion-design-agent-skills:motion-design-orchestrator`; elsewhere it is addressed by its bare name.

The orchestrator routes to:

- `motion-director`: runtime choice, timing/easing tokens, reduced-motion path for a component or UI surface.
- `site-motion-excellence-director`: whole-site choreography, scroll stories, premium motion spec, excellence gate.
- `web-motion-auditor`: review, debug and score existing motion with evidence.
- `remotion-video-agent`: Remotion compositions, MP4/GIF renders, captions, finishing generated footage.
- `generative-media-director`: style frames, image and video prompts, provider routing, provenance.
- `gsap-*` and `motion-design`: GSAP API and motion-principle references while implementing.

Always keep the gates: still frame before motion, reduced motion designed in the same pass, explicit authorization before paid generation or publication, evidence before any score.
