# Hermes Agent memory

Hermes writes `~/.hermes/memories/MEMORY.md` itself through its memory tool, so do not edit that file by hand. After installing the skills, send Hermes this message once:

```text
Remember: for any motion design, UI or web animation, transitions, motion QA, Remotion video, GIF/MP4 export or AI-generated image/video task, run the motion-design-orchestrator skill first; it routes to motion-director, site-motion-excellence-director, web-motion-auditor, remotion-video-agent, generative-media-director and the gsap-* / motion-design references.
```

For a single project, add the block in `memory/motion-design-routing.md` to the project's `AGENTS.md` or `.hermes.md`.
